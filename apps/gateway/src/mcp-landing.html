WHY MCPSHIELD

AI에게 도구를 연결하는 순간,
새로운 보안 경계가 생깁니다.

MCPShield는 도구 설치 이후의 업데이트까지 확인하고, 검증 결과를 실제 실행 허용 여부로 연결합니다.

업데이트마다 다시 검증

이름이 같은 MCP라도 코드와 도구 구성이 바뀌면 새로운 릴리스로 봅니다. 안전했던 과거 판정을 재사용하지 않습니다.

2-of-3 독립 판정

하나의 관리자 판단에 의존하지 않습니다. 여러 검증자의 결과를 모아 기준을 통과한 릴리스만 VERIFIED로 확정합니다.

실행 전에 차단

경고만 남기지 않습니다. REVOKED 또는 변조된 릴리스는 Gateway가 프로세스를 시작하기 전에 차단합니다.

FAQ

도입 전에
궁금한 점

데모와 현재 프로토타입의 범위를 정확하게 안내합니다.

MCPShield는 기존 MCP 서버를 대신하나요?

아닙니다. 기존 MCP 서버 앞에 Gateway로 놓여, 현재 실행하려는 릴리스가 검증된 상태인지 확인한 뒤 연결을 허용하거나 차단합니다.

왜 일반 데이터베이스 대신 블록체인을 사용하나요?

여러 검증자의 판정과 취소 이력을 한 운영자가 임의로 고치기 어렵게 만들기 위해서입니다. 민감한 원문은 올리지 않고 릴리스 지문과 판정 근거만 기록합니다.

지금 실제 ChatGPT에 연결할 수 있나요?

네. 위 공개 주소를 원격 MCP 앱으로 등록하면 읽기 전용 list_messages 도구를 사용할 수 있습니다. 현재 공개 데모는 가짜 메일만 반환합니다.

현재 어디까지 구현되어 있나요?

정적 스캔, AI 구조화 분석, 샌드박스 관찰, 2-of-3 검증, 온체인 상태, Gateway 실행 전 차단과 공개 MCP 연결까지 동작하는 해커톤 프로토타입입니다.

AI 도구 보안, 설명보다 직접 확인해 보세요.
